# hellonew

Projet de démonstration réalisé en suivant le tutoriel JCloudify (Java/Gradle),
utilisé pour se familiariser avec l'outillage JCloudify (génération de code,
publication vers Maven local, vérifications de santé du projet).

## Build

```bash
./gradlew build
```

Voir `.shell/` pour les scripts utilitaires du tutoriel (publication Maven
local, vérification de santé du projet).
